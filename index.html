02 — work

Things I've actually built.

demo-ready

Beacon

A peer-to-peer errand marketplace for OAU students.

Two-sided accounts — Task Posters and Runners — with escrow-style payments held until the job is actually done, in-app chat, and a demo wallet. I built the branding (Beacon Blue + Signal Gold) and full light and dark mode from scratch.

Role: solo — concept, design, build.

Java · Android Studio · RecyclerView · Fragments · SharedPreferences

in development · defense sep 11 🎓

UniEvents

Event management + ticketing for university events.

Students browse and register for campus events; organizers manage them. Registration mints a unique QR ticket, scanned at the door through the browser camera. Students apply in-app to become organizers; an admin approves. Paystack runs in test mode — a real payment flow without moving real money.

Role: Group 5 — I led product, account & platform decisions.

HTML · CSS · JavaScript · Firebase · Paystack API

active · freelance

Automation for local businesses

Lead capture + follow-up for small OAU-area businesses.

Make.com workflows that carry a lead from a Google Form into Notion and fire a follow-up email automatically — replacing work currently done by hand, for businesses doing it all manually today.

Role: freelance / client work.

Make.com · Notion · Google Forms · Gmail · WhatsApp Business API

built

Customer Support Triage

Routes and triages incoming support emails automatically.

Watches a Gmail inbox, sends each message to Claude to classify and summarize, logs the result to a spreadsheet, and pushes a triaged alert to Slack — so nothing sits unread and low-priority noise never reaches a human first.

Role: solo no-code build.

Gmail · Claude API · Google Sheets · Slack · Make.com

built

LeadBot

Qualifies inbound leads and routes them automatically.

A Google Form intake feeds Claude for lead qualification; every submission is logged to a spreadsheet, then qualified leads route onward — Slack for the team, Gmail for the lead — based on the result.

Role: solo no-code build.

Google Forms · Claude API · Google Sheets · Slack · Gmail · Make.com

in the lab 🧪

Deskbot

A voice assistant experiment — first step toward JARVIS.

Early prototype: push-to-talk, spoken replies, and a memory — with a hard rule that it asks before changing anything. The long-term target is a JARVIS-style assistant, built for real.

Role: solo experiment.

Python · speech-to-text · LLM APIs
